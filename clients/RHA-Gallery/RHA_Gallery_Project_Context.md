## 2. Produk & Cluster

**Cluster 1 — Planner Sekolah** (wipe-and-clean)
- Jadwal Pelajaran, Jadwal Piket, Struktur Organisasi, Absensi Kelas
- Pair terkuat: Pelajaran + Piket (**60×** dalam 1 order)
- Pembeli: wali kelas SD/TK/PAUD → membeli untuk **"Sistem"** (kerapian & ketertiban)

**Cluster 2 — Dekorasi Kelas / Poster Edukasi**
- Peta Indonesia (38 provinsi), Tata Surya, Peta Dunia, Poster Edukasi lainnya
- Pair terkuat: Peta Indonesia + Tata Surya (**35×**)
- Pembeli: orang tua anak 5–12 tahun & guru → membeli untuk **"Konten"** (belajar)

**Lini lain:** Papan Tulis Kayu, Planner Daily/Weekly, Poster/Frame Tokoh Pahlawan, Hiasan Dinding Gantung, Bingkai Custom.

| | **A. Ibu Guru Kreatif & Terorganisir** | **B. Bunda Proaktif & Edu-Decor** |

## 4. Insight Order (Shopee, Apr–Mei 2026 — 1.724 order valid)

- **83,2%** order single-product; **16,8%** multi-produk → ruang upsell besar
- **Hero products** (solo rate >65%): Peta Indonesia (71%, 363 order), Jadwal Pelajaran (69%, 323 order), Planner Daily/Weekly (85%), Papan Tulis Kayu (82%), Tokoh Pahlawan (89%)
- **Bundle driver:** Jadwal Piket, Jadwal Pelajaran, Peta Indonesia, Hiasan Gantung
- **Add-on only (solo rate <20%):** Struktur Organisasi, Peraturan Kelas, Pancasila/UUD, Matematika → jual dalam paket, bukan standalone
- **Dasar untuk:** Add-on Deal Shopee, paket bundling, dan pengelompokan **catalog CPAS**

## 7. Framework & Aturan Kerja

**Portofolio produk — BCG Matrix (K1–K4)**

| Kuadran | Traffic / CVR | Aksi |
| :--- | :--- | :--- |
| **K1** | Tinggi / Tinggi | Scale up budget, monitor ketat |
| **K2** | Rendah / Tinggi | Scale untuk tambah traffic (calon winner berikutnya) |
| **K3** | Tinggi / Rendah | Pertahankan budget, perbaiki katalog/faktor "X" |
| **K4** | Rendah / Rendah | Turunkan / alihkan budget |

**Aturan penting**
- **ACR 10%** = batas kelayakan komisi; **10–15%** = zona observasi/evaluasi bersama (tidak mengubah komisi)
- Scale budget harus mengikuti **CVR**, bukan hanya spend
- Campaign branded/keyword **jangan dihapus** saat restrukturisasi
- CPAS: product set = **katalog grouped**, bukan produk satuan; **Kode Produk** numerik diambil dari **Seller Centre**, bukan dari export order
- YoY dengan periode berbeda panjang → normalisasi **run-rate harian**
