# Ekstensi Chrome (v2)

Salin ke folder ini file ekstensi v2 yang SUDAH LOLOS UJI, apa adanya:

    manifest.json  datasets.js  injected.js  content.js  background.js  popup.html  popup.js

Termasuk tambalan status `disabled` di popup.js dan background.js bila sudah dipasang.
Pasang: `chrome://extensions` → Developer mode → Load unpacked → pilih folder `extension/`.
